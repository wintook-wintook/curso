# 📊 Dashboard Moderno - Proyecto Equipo

Dashboard interactivo y responsive con diseño moderno para gestión de datos y estadísticas.

## 🚀 Características

- ✅ Diseño responsive y moderno
- ✅ Animaciones suaves y transiciones
- ✅ Tarjetas de estadísticas interactivas con hover effects
- ✅ Tabla de transacciones con estados
- ✅ Reloj en tiempo real
- ✅ Gradientes y efectos visuales modernos
- ✅ Footer con links funcionales

## 📦 Instalación

### Clonar el repositorio
```bash
git clone https://github.com/TU-USUARIO/proyecto-equipo.git
cd proyecto-equipo
```

### Abrir en navegador
Simplemente abre el archivo `index.html` en tu navegador favorito:
```bash
# En Windows
start index.html

# En Mac
open index.html

# En Linux
xdg-open index.html
```

No requiere instalación de dependencias ni servidor local.

## 🎯 Uso

El dashboard muestra:

1. **Estadísticas principales** (4 tarjetas):
   - Usuarios totales
   - Ingresos del mes
   - Pedidos realizados
   - Tasa de conversión

2. **Sección de gráficos**:
   - Área para gráfico de ventas
   - Lista de actividad reciente

3. **Tabla de transacciones**:
   - Últimas operaciones
   - Estados: Completado, Pendiente, Cancelado

## 🌿 Flujo de Trabajo Git

### Ramas principales:
- `main` - Código en producción (protegida)
- `dev` - Rama de desarrollo

### Ramas de características:
- `feature/colaborador1-header`
- `feature/colaborador2-sidebar`
- `feature/colaborador3-footer`

### Comandos básicos:
```bash
# Actualizar tu rama
git pull origin dev

# Crear nueva rama
git checkout -b feature/nombre-funcionalidad

# Hacer commit
git add .
git commit -m "Descripción del cambio"

# Subir cambios
git push origin feature/nombre-funcionalidad
```
